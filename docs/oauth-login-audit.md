## 当前使用方式与边界

- 本地 UI 绑定回环地址且没有显式管理令牌时，自动启用私有账户目录与本地会话，无需手动设置两个环境变量。默认目录为 `$XDG_CONFIG_HOME/xgate/accounts`，未设置时为 `$HOME/.config/xgate/accounts`。
- 无后端也可登录、导入、编辑模型规则、下载、刷新和保存账户。**保存账户不会自动创建代理路由**；后续需要转发流量时再绑定配置中的后端和路由。
- 非回环监听仍要求显式管理认证。本地会话不是公开管理接口；真实连接来源和同源检查仍保留。
- 自动回调使用供应商登记的 localhost 端口；占用时保留授权链接并提示手动提交完整回调 URL。不能以“端口暂时可用”推断它始终可用。
- 测试使用临时凭证和本地 HTTP 供应商。真实供应商账号的授权、套餐资格及未来协议变化未通过真实账号验证；没有调用用户真实账号进行付费请求。
- 未绑定账户和已绑定账户均保留已有的修订号冲突检查、PKCE/state 校验、令牌隐藏和私有文件权限。
